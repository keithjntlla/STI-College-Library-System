# Archive

This folder stores obsolete one-off scripts and scratch files that were produced during earlier agent-assisted development.

They are **not** part of the running application. Do not import from here, and do not run these scripts as part of normal setup.

| Subfolder | Contents |
|-----------|----------|
| `codemods/` | Historical `fix-*`, `update-*`, `add-*`, seed, and patch scripts |
| `scratch-ui/` | Stray UI copies that never belonged in the app tree |
| `misc/` | Other non-runtime leftovers |

Day-to-day development uses `apps/web`, `apps/api`, `database/`, and `docs/` only.
